# The Artisan Bamboo Spiral Journal & Precision Pen Set
## Luxury Product Showcase Website by Anirban Mandal

A premium, modern, visually immersive product showcase website designed and engineered by **Anirban Mandal**.

Inspired by the reference luxury design aesthetic (dark moss/forest green palette, floating pill navigation, glowing neon accents, and glassmorphism), this website features a cinematic background video experience created from the provided 230 Full HD (1920×1080) product frames.

---

## 🌟 Key Features

### 1. Cinematic Background Video & Interactive 360° Canvas
- **Automated Cinematic Playback:** Streams all 230 frames seamlessly at 30 FPS in a continuous loop.
- **Interactive 360° Scrubbing:** Allows visitors to grab and drag with mouse or touch to rotate the bamboo journal in full 360 degrees.
- **Interactive Hotspot Targets:** Direct jump buttons for the *Solid Bamboo Cover (0°)*, *Precision Pen Dock (75°)*, *Kickstand Easel (125°)*, and *Steel Twin-Wire Spine (290°)*.
- **HUD Readouts:** Live angle indicator (0°–360°), play/pause toggle, and speed multiplier (0.5x, 1.0x, 1.5x, 2.0x).
- **Concentric Ambient Rings & Glow:** Nature-inspired radial aura and subtle bokeh matching the reference screenshot.

### 2. Trust Badges & Guarantee Ribbon
Placed directly below the hero section with frosted glass pill containers:
- **FSC Certified Raw Materials**
- **100% Plastic-Free Packaging**
- **Carbon-Neutral Shipping**
- **30-Day Tactile Satisfaction Guarantee**

### 3. Product Architecture & 5 Highlights
Presented in a responsive 5-column glassmorphic grid inspired by the reference design:
1. **100% Solid Natural Bamboo Hardcover** (Laser-cut and sanded smooth, highlighting organic wood grain).
2. **Integrated Pen Dock & Matching Stylus Pen** (Dedicated cutaway edge holding a weighted bamboo and brushed steel ballpoint pen).
3. **Heavy-Duty Twin-Wire Binding** (Black powder-coated double-loop metal spiral allowing a 360° flat lay).
4. **Elastic Security Band** (High-tension black retention strap keeping confidential notes secure).
5. **Ink-Proof Recycled Paper** (100 GSM unbleached, acid-free recycled paper preventing bleed-through and ghosting).

### 4. Interactive Ruling Simulator & Laser Engraving Studio
- **Paper Ruling Switcher:** Live interactive preview of **College Ruled**, **Dot Grid**, and **Blank Sketch** on unbleached 100 GSM warm recycled paper texture.
- **Laser Engraving Customizer:** Type your name or initials to preview realistic laser etching on bamboo timber in real time.

### 5. Glassmorphic Sustainability Sections
- **Section A: Sourced From Nature** (Natural Bamboo Wood, Recycled Fibre Paper, Soy-Based Inks, Black Anodized Steel).
- **Section B: Why Choose Bamboo?** (Zero Plastic Footprint, Durability Over Time, Refillable & Reusable).

### 6. Interactive Eco-Cart & Quick Order Drawer
- Slide-out order drawer with quantity selector, ruling selection, free shipping progress bar, and instant simulated eco-checkout with order reference confirmation.

### 7. Generative Ambient Nature Sound (Web Audio API)
- Optional calm bamboo forest wind rustle and pentatonic bell chime synthesis (100% zero external audio files needed).

## 🚀 How to Run Locally

You can run the built-in zero-dependency preview server:

```bash
# Start server
npm start
# or
node server.js
```

Open your browser at:
`http://127.0.0.1:3000`

Or simply double-click `index.html` to open directly in any modern browser!
